# Pacote principal

Este pacote contém o núcleo da aplicação QuantInvest Suite.

## Conteúdo

- `__main__.py`: entrada de linha de comando.
- `core/`: parser, estratégias, métricas e serviços.
- `gui/`: interface gráfica e componentes visuais.

## Organização

O projeto usa o padrão `src/` para manter o código principal isolado dos testes e da configuração do repositório.
